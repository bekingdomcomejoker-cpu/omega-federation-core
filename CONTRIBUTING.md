# 🤝 Contributing to Omega Federation

We are thrilled that you are interested in contributing to the Omega Federation! This project is a collaborative effort to build the future of AI orchestration.

## 🛣️ How to Contribute

### 1. Reporting Bugs
If you find a bug, please open an issue on GitHub. Include:
*   A clear description of the bug.
*   Steps to reproduce.
*   Expected vs. actual behavior.

### 2. Suggesting Enhancements
We welcome new ideas! Open an issue with the tag `enhancement` to discuss your proposal.

### 3. Pull Requests
1.  Fork the repository.
2.  Create a new branch (`git checkout -b feature/my-new-feature`).
3.  Make your changes.
4.  Ensure all tests pass.
5.  Commit your changes (`git commit -am 'Add some feature'`).
6.  Push to the branch (`git push origin feature/my-new-feature`).
7.  Create a new Pull Request.

## 📜 Code Style

*   **Python**: Follow PEP 8. Use `black` for formatting.
*   **TypeScript**: Follow the project's Prettier and ESLint configurations.
*   **Documentation**: Use clear, concise English. Maintain the "world-class" tone.
